# Planteamiento del proyecto

**sysml-v2-rulechecker** es la propuesta inicial de un analizador de calidad para modelos SysML v2. Se centra en un subconjunto explícito de elementos estructurales y relaciones de requisitos. Las reglas producen diagnósticos reproducibles y localizables; la IA generativa ayuda a interpretarlos y a revisar posibles correcciones.

La [Actividad 0](00-planteamiento.md) formula el problema de investigación, la hipótesis y los objetivos propuestos para validar con el profesor. El estado de la cuestión está pendiente de completar por el grupo.

> Este sitio describe una propuesta de investigación. No presenta resultados medidos ni afirma que el prototipo ya esté implementado.
